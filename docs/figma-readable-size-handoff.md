# Mandoubi admin — readable desktop sizes

The current Operations Center direction is drawn at a miniature preview scale inside a fake browser frame, not at the size of a real application. Type is between 6px and 11px, and the product table is 7px, so the screen looks too small when it opens on a desktop.

Keep the visual language as it is: Arabic right-to-left, sidebar `#12231d`, green `#207554`, page background `#F2F5F3`, and the fonts IBM Plex Sans Arabic and Noto Kufi Arabic. Change the sizes only. Do not zoom the whole frame.

Use these sizes as the real text styles for the admin screens:

| Element | Current size | Required size |
|---|---|---|
| Sidebar width | 205 | 260 |
| Nav items | 10 / height 38 | 15 / height 44 |
| Wordmark | 17 | 20 |
| Wordmark caption | 8 | 12 |
| Logo | — | 44×44 |
| Breadcrumb | 7 | 13 |
| Page title | 18 | 26 |
| Page description | 8 | 14 |
| Table header | 7 | 13 |
| Table cell | 7–8 | 14 |
| Secondary line inside a cell | 7 | 12 |
| Barcode | 6 | 13 |
| Product thumbnail | 28 | 40 |
| Badge | 7 | 12 |
| Row action button | 28 | 36 |
| Standard button | 8 / height 36 | 14 / height 40 |
| Search and filter label | 6 | 12 |
| Search field | 8 | 15 |
| Form fields | 8–10 / height 34 | 15 / height 44 |
| Field label | 10 | 14 |
| Section title | 10 | 16 |
| Section description | 7 | 13 |
| Pagination | 7 / height 26 | 14 / height 36 |
| Confirm dialog title | 12 | 20 |
| Confirm dialog body | 8 | 15 |
| Sign-in button | 11 / height 40 | 16 / height 48 |

Leave the large sign-in headline (about 38) as it is. Everything else, including forms, the exchange-rate card, and status switches, should use the same readable scale.

Design the screens at a width of 1440. A wide table should scroll horizontally inside its card instead of shrinking the type to fit the width.
